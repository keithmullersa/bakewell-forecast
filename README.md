# bakewell-forecast

Self-contained HTML paragliding forecast dashboard for Mount Bakewell, WA.

Site: https://keithmullersa.github.io/bakewell-forecast/

`index.html` is generated daily by the Muppet Forecast Learner model and overwritten. Do not hand-edit it. `dashboard.html` is an identical copy. GitHub Pages serves this repository from the `main` branch root (`.nojekyll` disables Jekyll processing).
